# Backend dependencies for the Orbital Rendezvous Simulator API.

# the repository root requirements.txt, because this API imports orbital_core

#
#     python -m pip install -r requirements.txt              (repo root)
#     python -m pip install -r web-platform/backend/requirements.txt
#
# Pinned to the versions verified working on Python 3.14.6, the interpreter the
# published numerical results were produced with.
#
# Note on pydantic: 2.10.x has no cp314 wheel and its pydantic-core falls back
# to a Rust source build, which fails without a toolchain. 2.13.x ships a
# prebuilt wheel for 3.14. Install with --only-binary=:all: to catch any future
# recurrence loudly rather than by silently attempting a compile.
